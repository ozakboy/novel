# 第 4651 篇

## 第4617章拓世道君

第4617章拓世道君

拓世道君，真仙教的第二位道君，摩仙道君的徒弟，曾經是充滿著傳奇色彩的道君。

但是，如果說，你以為拓世道君乃是天賦過人，天賦無雙，年輕之時驚才絕艷，那就是大錯特錯。

甚至可以說，拓世道君，根本就與天賦無雙沒有任何關系。

在世人所想象之中，作為摩仙道君的親傳弟子，後來的絕世無敵道君，拓世道君應該是天賦異稟，絕世過人才對，事實上，並非如此。

在摩仙道君眾多弟子之中，拓世道君是資質平平之人，而且在年輕之時，乃是庸碌無為，甚至更為離譜的是，拓世道君，作為摩仙道君的親傳弟子，他卻不修練摩仙道君的功法，這是在那個時代，所無法想象的。

摩仙道君，一生無敵，驚艷無匹，堪稱乃是萬古無雙的道君，乃是萬古十大道君之一。

摩仙道君，在其一生，座下弟子眾多，而且，可以想象，無敵如摩仙道君，他又焉會輕而易舉去收徒呢？

可以說，在那樣的時代，能拜於摩仙道君的人，那都是天賦無雙，血統高貴，又或者擁有著獨一無二的東西，總之，在那個時代，能成為摩仙道君座下弟子的人，都是天之驕子，乃是天才之中的天才。

所以，在那個時代，摩仙道君座下有十大傑出弟子之說，摩仙道君的十大傑出弟子，都稱得上是當世無敵，放在任何一個地方，都足可以橫掃天下，放在任何一個時代，都是璀璨奪目。

但是，拓世道君卻偏偏是一個例外，拓世道君是在摩仙道君的所有弟子之中，資質最差的一個，可謂是資質平平，扔在大眾之中，會一下子泯沒於茫茫人海，整個人是毫無亮點可言。

在那樣的一個時代，沒有人知道為什麼摩仙道君會收了這樣的一個弟子，甚至一生修行都是十分淺薄。

這還不是最為離譜的事情，最為離譜的是，在摩仙道君臨行之時，指定為拓世道君為繼承人，掌執真仙教的大統。

這樣的事情，在那個時代，可謂是天下嘩然，莫說是世人不敢相信，連摩仙道君座下的無敵神皇，絕世弟子，都無法相信。

在那個時代，摩仙道君何等是羣星璀璨，何等的天才輩出，何等的無敵之輩多如牛毛。

可以說，摩仙道君隨便挑選其他的人繼承自己的大統，掌執真仙教大權，都是比拓世道君強一百倍，強一千倍，強一萬倍。

畢竟，在那個時候，拓世道君被指定為繼承人之時，拓世道君還是實力普普通通的弟子而已，那怕他是摩仙道君的親傳弟子，但是，他的道行，也只不過是普普通通。

相比起那些絕世無雙、璀璨無比的同門師兄弟而言，普普通通的拓世道君，可謂是不值得一提。

在那個時代，沒有人能想得明白，為什麼摩仙道君有著那麼多傑出的弟子可以選擇，有著那麼多的無敵神皇可以選擇，卻偏偏要選擇一個平平無奇的弟子作為自己的繼續人，作為掌執真仙教大統的人選。

在那個時候，是所有世人所無法理解，甚至摩仙道君座下有弟子或神皇都是憤憤不平，畢竟，平平無奇的拓世道君根本就是沒有這個能力與資格去繼承摩仙道君的大統，去掌執舉世無敵、統御八荒的真仙教。

摩仙道君就是摩仙道君，言出即法，他選擇了平平無奇的拓世道君作為繼承人，不論是絕世無雙的弟子，還是舉世無敵的神皇，都必須遵守，摩仙道君的神威，是無任何人可以凌駕的。

摩仙道君走了之後，雖然在真仙教之內，在八荒之間，有不少人想謀篡拓世道君的大位，甚至是想謀害拓世道君。

但是，最終都以失敗而告終，雖然也有摩仙道君的弟子不服拓世道君，或者無敵神皇欲有野心。

但是，總體而言，摩仙道君座下的傑出弟子、無敵神皇，大多數還是團結一致，上下齊心。

所以，拓世道君被指定為繼承人之後，摩仙道君的多數傑出弟子、座下神皇，都擁護拓世道君，遵守摩仙道君的法旨，讓平平無奇的拓世道君坐穩大統之位。

最終，本是平平無奇的拓世道君沒有讓摩仙道君失望，在摩仙道君諸多無雙的傑出弟子都無法證得道果，無法成為道君之後，白發蒼蒼的拓世道君，在暮年之時，竟然證得道果，成為了無敵道君，終於凌駕在了摩仙道君所有傑出弟子、所有無敵神皇之上。

正是因為如此，拓世道君的事跡，譜寫出了傳奇無比的故事。

在後世之人看來，摩仙道君就是摩仙道君，可謂是慧眼識珠，最終還是挑選上了拓世道君，也使得拓世道君成為真正的道君，超越了所有天才。

這樣的慧眼，讓後世之人驚嘆不止，畢竟，在那個時代，摩仙道君指定拓世道君之時，那都是天下嘩然。

直到拓世道君證得道果，成為道君，舉世無敵之後，世人才知道，摩仙道君就是摩仙道君，這就是天下人與摩仙道君之間的差距。

拓世道君的傳奇色彩，也是給了後世之人無限的希望，也鼓勵著千千萬萬的修士強者，堅持修道，一路前行。

畢竟，對於天下無數的修士強者而言，天才，那終究是屬於極少數，絕大多數的修士強者，也只不過是平平無奇的普通之輩罷了。

與任何天才相比，普通修士的平平無奇，會使得他黯然失色。

然而，拓世道君的傳奇事跡，也讓天下無數的平平無奇修士，對自己的修道人生看到了希望，心裏面也有了火苗，或許，平平無奇的自己，會成為下一個拓世道君，或許，平平無奇的自己，在修道之上，堅持下去，必定會有一番作為，那怕是年老之時纔有大成之日，這總比年輕之時便放棄好。

拓世道君，一個傳奇色彩的道君，也是說明瞭摩仙道君的慧眼識珠。

此時，真仙靈少血氣一浮現的時候，拓世光芒吞吐，所有人都知道，真仙靈少所修練的，便是真拓世道君所留下來的《拓世寶典》。

“真仙教的無敵功法，道君之術，實在是太多了。”看著真仙靈少身上所浮現的拓世光芒，也有不少修士強者為之羨慕，低聲地說道：“任何資質好的弟子，都有機會修練道君功法。《拓世寶典》，這樣絕世無雙的寶典，真仙靈少這樣的一個第三代弟子，就可以修練整本寶典了。”

這也難怪那麼多的修士強者為之羨慕，畢竟，對於許多的大教疆國而言，那怕是道君傳承而言，道君功法，往往是能被視之為鎮教功法，普通弟子，根本就沒有資格修練，也沒有那個能力去修練，除非是宗門的大人物，或者是立了大功的弟子，又或者是天賦無雙，被視之為傳人的弟子，纔有資格修練。

而且，修練道君功法，那也只是修練其中一門功法罷了，而不是修練道君的整本寶典。

但是，真仙教出過那麼多的道君，道君功法，可以稱得上是天下最多的門派，所以，真仙靈少這樣的年輕一輩，都有資格修練整本《拓世寶典》，這怎麼不讓天下修士強者為之羨慕嫉妒呢。

對於許多大教疆國，那怕是道君傳承而言，能修練整本道君寶典的人，對於一個門派而言，往往是某一些強大的老祖，又或者是位高權重的掌門，普通弟子，根本就是不可能的事情。

所以，在這個時候，不知道有多少修士強者望著真仙靈少，羨慕萬分，出身於真仙教，就是好。

“現在，你道歉還來得及。”此時，真仙靈少冷冷地說道：“否則，莫怪我心狠手辣，親手毀了你。”

真仙靈少這樣的冷冷的話說出來，猶如利刃一樣，刮在人的心上，讓人隱隱發痛，忍不住打了一個冷顫。

真仙靈少這話僅僅是對李七夜說而已，但是，其他人聽到，都感受到了那種痛，試想一下，如果真仙靈少的神威壓在自己的身上，那是何等的可怕。

“吹牛的話，我是聽多了。”李七夜輕輕地擺了擺手，說道：“如果你想自尋死路，那應該給自己先備一副棺材，至少還能為自己收屍。”

“好大口氣。”聽到李七夜這樣一說，不少人都為之抽了一口冷氣，有年輕一輩不以為然，嘀咕地說道：“好像他能打贏真仙靈少一樣，好像他是勝券在握一般。”

“這個就不好說了。”有一位對李七夜有所瞭解的大人物，不由沉嘀了一聲，說道：“他可是斬殺了六翼神使的人，雖然六翼神使比不上真仙靈少，但是，好歹也是真仙教的天才呀。”

這樣的話，就讓人不由為之沉思，有一些強者也覺得是有道理，六翼神使畢竟是真仙教主的親傳弟子，實力就算比不上真仙靈少，但是，也不見得會有多差。

“好——”聽到李七夜這樣一說，真仙靈少的目光一下子冷厲無比。

(本章完)
