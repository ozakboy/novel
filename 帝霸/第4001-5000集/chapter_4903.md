# 第 4903 篇

## 第4869章三元徵天座

第4869章三元徵天座

八匹殿被清理之後，露出了山峯底座，整座山峯底座看起十分奇怪，因為留下的山峯底座，在這個時候仔細去看，又覺得這不是一座山峯的底部。

似乎，這樣的一座山峯底座，整像是一座巨大無比的雕像底座。

不論是山峯底座，還是巨大無比的雕像底座，它都是被掰斷的，整個底座的斷口乃是參差不全，犬牙交錯，看起來十分的奇怪。

此時，李七夜站這山峯底座之上，伸手去撫摸著山峯底座的斷口。

烈焰狂刀跟隨著李七夜，仔細去看這些底座的裂口，仔細去看，他也覺得這些裂口覺得十分奇怪。

這參差不齊的斷口，沒有任何延遲的痕跡，也就是說，被甚麼強大到無法想象的力量瞬間掰斷，沒有絲毫的滯慢。

這樣的感覺，就好像是被鋒利無比的寶物或者神劍所斬開一樣，但，它的斷口卻是參差不齊，一看就讓人知道這絕對不是什麼神兵利器所斬斷的。

伸手去撫摸那些斷口的時候，發現有很奇怪的斑點，這些斑點不是底座自身所有的，而是似乎是什麼力量，瞬間在這裏凝固，然後又瞬間消失，就好像是有什麼東西可以瞬間滲透入其中一樣，那種感覺，完全是說不出來，至少是超越了烈焰狂刀的理解。

“這是什麼東西呢？”烈焰狂刀不由好奇地問，在這個時候，他也覺得，這樣的底座，並非是什麼山峯。

“一個了不得的東西。”李七夜輕輕地撫摸著斷裂口。

過了好一會兒，他不由抬頭看了一眼天空，淡淡地說道：“看來，的確是沒錯，這鬼東西，沒有死在天譴之下。”

烈焰狂刀不由為之一怔，也不由抬頭，問道：“什麼是鬼東西？”

李七夜笑了一下，沒有說，隨之，看著那些擺在山腳下的巖石山體，吩咐地說道：“都抬上來吧。”

在李七夜吩咐之下，那些被挖出來的巖石山體被一一拖拽上來。

在這個時候，烈焰狂刀才發現，這在外面挖出來的巖石山體，和八匹殿的巖石山體是一模一樣的，它們的質地、顏色都是一樣的。

“都裝上去吧。”李七夜吩咐一聲，讓八匹縱衛騎做苦力，自己親自指點八匹縱衛騎去鑲嵌這一個又一個殘破的山體。

隨著這樣的殘破巖石山體被一一駁接鑲接而上的時候，烈焰狂刀在這個時候才明白李七夜為什麼要拆掉了八匹殿了。

原來，八匹殿的整個山體乃是一體的，只不過，整個山體被掰斷之後，那些崩碎的部分，散落在外面，現在被八匹縱衛騎從深埋的泥土中挖出來。

現在，李七夜要把這所有破碎的山體鑲接回去，所以，就必須拆掉整個八匹殿。

隨著一塊塊的巖石山體被鑲接回去之後，一個巨大無比的雕像慢慢展露在了所有人的面前。

最終，一座巨大無比的雕像出現在了所有人面前。

這一座巨大無比的雕像，仔細看，主體是一尊巨人，這一尊巨人古老無比，甚至是整個巨人的身體乃是以簡單無比的手法去勾勒出來，不論是面容還是衣著，都看起來簡單無比，沒有任何細節可言。

這個巨人抬頭望天，那怕是那一雙眼睛乃簡簡單單的石眼，當他做出這樣的動作之時，讓所有看到這一座巨人雕像的人都心神一震，因為這一尊巨人抬頭望天的時候，它就好像瞬間破天而起一樣，擁有著讓人想象不到的力量，似乎，它可破天，可滅世。

在這尊巨大無比的巨人身旁有另外三尊石人，相比起眼前這一尊巨人而言，這三尊石人顯得小了很多，就好像是一個巨人帶著三個孩子一樣。

這三個石人有兩位站在他的身前左右，而另一位站在了中間，雙手高舉，呈捧狀，好像是雙手要捧著什麼一樣，直齊於巨人胸前。

但是，在他的雙手之中，卻沒有任何東西。

又或者說，這個高舉雙手的石人，有什麼要獻給這個巨人，又或者說，是這個石人為這個巨人捧著什麼東西一樣。

在這個時候，所有人一看，都能感受到，這樣的一尊巨人，可以俯視整個八匹王朝。

看著這樣的巨人雕像，一時之間，八匹縱衛騎也好，烈焰狂刀也罷，都呆呆看著出神，那怕這樣的雕像沒有任何神威，他們看著這樣的雕像之時，卻有著被威懾的感覺，甚至有一種臣伏的沖動。

在這個時候，本是對拆除八匹殿有所怨言的人，看著眼前這樣的雕像，所有怨言都是煙消雲散了，一時之間，都覺得，當年的八匹殿建在這裏，的的確確是有一種暴餮天物的感覺。

“這，這是什麼雕像。”看著這樣的巨人雕像，烈焰狂刀不由喃喃地說道　　“三元徵天座。”李七夜看著眼前這座雕像，徐徐地說道。

“三元徵天座，什麼三元呢？”烈焰狂刀回過神來，下意識地看著另外三個石人，說道：“是，是指這三個石人嗎？”

“看仔細一點。”李七夜笑了一下，淡淡地說道。

烈焰狂刀得到了提醒，仔細去觀摩一會兒，突然有發現，雖然這三個石人的雕刻也是十分粗糙，但是，它們都有自己的特徵，烈焰狂刀不由失聲地說道：“難道，難道它們代表著天、神、魔三族？”

“對，沒錯。”李七夜輕輕點頭。

“三元徵天座。”烈焰狂刀回過神來，不由說道：“這，這是指天、神、魔徵天嗎？”

“不是。”李七夜笑了一下，說道：“說的是三元。”

“三元，三元是誰？”一下子又繞回來了，把烈焰狂刀都繞得滿頭霧水，不知道三元指的是什麼。

“三元開泰呀。”李七夜說道。

“三元開泰。”烈焰狂刀呆了一下，回過神來，失聲地說道：“難道，難道是指三種血統嗎？”

李七夜看了烈焰狂刀一眼，淡淡地笑了一下，說道：“看來，你知道不少，這個說法你也知道。”

“殿下過獎了，這是陛下生前說過，我才知道。”烈焰狂刀說道：“陛下生前，曾去探索過血統的傳說，去挖掘過古籍。傳聞說，神、魔、天三族擁有著十分古老的傳說血統，甚至說是什麼仙血，然後又說，這個的血統說法，有一種更為古老的傳說，叫三元開泰。”

“你們陛下，的確是挖掘了不少信息，只不過，這僅僅是一小部分罷了。”李七夜淡淡地笑了一下。

“古族的三大仙血，就是三元開泰嗎？”烈焰狂刀不由問道。

李七夜不由笑了一下，輕輕搖頭，說道：“不，準確地說，三元開泰不是三大仙血，也不是三種血統，而是一種血統。”

“一種血統？”李七夜的話讓烈焰狂刀更是發懵了。

“三元開泰，只是一種血統，後來，一分為三，便是有天、神、魔三大血統之說。”李七夜看著眼前這巨大的雕像，說道：“在那遙遠的紀元，它有一個稱謂。”

“遙元的紀元？”烈焰狂刀不由十分好奇，問道：“怎麼樣的紀元呢？”

李七夜淡淡地說道：“紀元之初，乃是一體，後被分為上下。”

“上界、下界嗎？”烈焰狂刀知道這個，說道：“陛下說過，他就是來自於下界，稱之為八荒。”

“但，那個時候，不叫八荒，叫九界。”李七夜笑了一下。

“九界。”烈焰狂刀不由細細地喃語，但是，他對這樣的稱謂，並沒有什麼印象，只是聽八匹道君說過，下界之時，稱這八荒，也是一個廣袤的世界。

“九界十三洲呀。”李七夜輕輕地說道：“可惜，總是有人不死心。”

“稱為九界十三洲紀元嗎？”烈焰狂刀說道。

李七夜輕搖頭，說道：“那隻不過是世人自認為罷了，它並非叫九界十三洲紀元，它有著它真正的稱謂——三泰紀元。”

“三泰紀元。”這樣的稱謂，烈焰狂刀聽都未聽過。

回過神來，說道：“這，這三泰紀元，是，是天、神、魔三族開創嗎？”

李七夜不由笑了起來，搖頭說道：“古族三支，又焉有實力去開創一個紀元，他們只不過是這個世間的生靈，乃是上天的造物。”

說到這裏，李七夜頓了一下，徐徐地說道：“只不過，天地分，紀元初之時，有更古老的存在。”

“那是怎麼樣的存在？”烈焰狂刀不敢想象，一個紀元的開創，那豈不是遠遠強大於古之大帝這樣的存在。

“大道混元。”李七夜說道：“只是可惜了。”

“那，那三元開泰的血統，是不是誕生於此呢？”烈焰狂刀好奇。

李七夜輕輕搖頭，說道：“三元開泰血統，並非源於此，大道混元、天生三元真我，又焉是三元開泰的血統所能相比的。”

“那這雕像呢？”烈焰狂刀看著眼前巨大無比的雕像。

李七夜說道：“三元開泰，有人，也曾是守護著這個世界，立下了不朽之碑，守望天地。”

“守護這個世界。”不知道為什麼，聽到這樣的話，烈焰狂刀心裏面就有不祥之感。
