# 第 2012 篇

## 第2071章陶婷的心事

第2071章陶婷的心事

“白鶴高飛。”修羅輕輕地喃喃地說道：“這一份榮耀該屬於老師，老師苦心孤詣並不是為了自己，而是為了這個世界，又有誰知道老師在這背後的付出呢。往來於九界與第十界之中，一次次的生死以赴，一次又一次折磨錘煉，最終老師才打造出了我們。”

“這個我知道。”李七夜淡淡一笑，說道：“我只是想做點事而己，畢竟我生於這個時代。只不過，也該為你們正名之時了，你們沉寂了一個又一個時代，潛伏了一個又一個時代，你們的付出，也應該得到回報，你們是九界和第十界的英雄。”

“若是在這世間，我們需要感謝的，就是老師。”修羅輕輕地說道：“我們並不欠這個世界，但，我們欠老師的。”

“不用了。”李七夜笑著說道：“你們當年不罵我虐待狂就很不錯了，畢竟這一條路不容易，經歷了太多的折磨了。”

修羅也不由露出了笑容，說道：“不經風雨，又怎能見得彩虹。”

“是呀，這將會是一場大暴雨，希望不止是能熬過支，當風雨過後，就能見得彩虹。大暴雨將會沖涮著這個世界的污垢，沖刷著這個世界的黑暗。這一條道路有著太多的先賢付出了，不論是驕橫，還是明仁，又或者是青木，他們一路前行，我們也應該是他們的後盾，後人也應該去堅守這個世界，不能說敵人太強大、黑暗太可怕，我們就有藉口放棄這個世界！”李七夜徐徐地說道。

“老師一直在堅守著這個世界，從來沒有放棄過，不管世界如何變，不管世人如何看待老師，老師依然在堅守著。”修羅輕輕地說道。

李七夜搖了搖頭，說道：“不，是你們，我終有一天會離開的，這個世界還需要你們去堅守，如果說未來誰能去守護這個世界，那麼就需要你們這樣的人，需要如你們這樣的大帝仙王，需要世帝這樣的領袖。”

“可惜，世帝非我族。”修羅不由感慨地說道。

“世帝終究是世帝。”李七夜笑了笑，說道：“雖然說我與他世代為敵，他也比任何人都想取我的首級。但，在大是大非面前，世帝比任何人都清醒，任何人都睿智。或者，有一天世帝他會身不如己，畢竟他背後代表著一大羣龐大可怕的力量，但是，真的到了危難的一天，請相信，世帝他會站出來的，他並非是一個量小之人，那怕他是我的敵人，他依然是一個了不起的人，是一個有擔當的人，他是天生的領袖！”

若是外人聽到這樣的話，一定會覺得不可思議，陰鴉與世帝世代為敵，陰鴉曾經一次又一次橫推天、魔、神三族，而世帝也曾一次又一次追殺陰鴉，可以說他們是死對頭，誓不兩立，在他們兩個人之間，不是你死便是我亡，但現在李七夜卻對世帝如此高的評價。

“世帝終究是世帝呀。”修羅不由喃喃地說道。

李七夜笑了一下，說道：“如果說，舉世之間有誰能讓我信任，那麼淺老頭是其中一個，未來有一天我是遠走世間了，羣龍無首之日，必要之時也可以與淺老頭並肩作戰！”

“老師的意思我明白。”修羅點了點頭，說道。他也是屬於站在巔峯上的人物，雖然說世帝與李七夜是世代為敵，但是世帝是一個君子，君子值得人去信任，去託付，特別是大難之時。

李七夜在這洞府之內與修了很久，聊了很多，特別是面對於天院即將到來的災難，他們更是仔細規劃，這將會是一場血戰，不止僅僅關系著他們天院，甚至關系著百族的未來。

對於百族來說，可以沒有帝統仙門，可以沒有古府、奇竹山這樣的傳承，但是不能沒有天院。

天院倒下了，這就會意味著百族修士的這一條道路從開放走向封閉。曾經何時，天院為百族培養了多少人才，多少叱吒風雲的人物從天院走出來。

雖然說百族今天的興盛，少不了驕橫仙帝、飛仙帝、古純仙帝、萬骨仙帝、一葉仙王等等諸位百族仙王和九界仙帝的付出，但是，沒有天院，百族也一樣沒有今天，因為天院為百族培養了無數的修士，為這片大地播撒下了無數的種子，這使得整個百族變得無限的可能，畢竟獨木難撐大廈！

所以，對於李七夜來說，必要之時，為了保全天院，他會毫不猶豫展開一場大屠殺，屠殺掉一位位大帝仙王，屠滅掉一個個帝統仙門！

李七夜與修了許久之後，最後才離開修羅的洞府，回到了天院。

“嗡”的一聲響起，李七夜再一次回到了小院之中，此時老僕依然站在那裏，他低著頭，一句話都沒有說。

李七夜向他點了點頭，然後就離開了，走出了小院。

“吱”的一聲響起，此時老僕默默地關上了木門，小院依然是悄然無聲，這樣的一座小院不論如何都不引人注目。

李七夜回首看了一眼小院，笑了笑，然後飄然而去。

行走在書城之中，看著滿街來來往往的人流，看著那是朝氣蓬勃的學生，李七夜也不由有些感慨，曾經有多少朝氣蓬勃的學生從天院走出去，面對著這個世界的風風雨雨呢。

曾經何時，他也曾經是在天院任教過，他也曾經是送走了一個又一個學生。

“李道兄不，不，不，老師”李七夜行走在街道上的時候竟然遇到了熟人，只見在街道旁的酒家，在臨窗的位置上坐著一個女孩，她看到李七夜的時候不由叫了一聲，向李七夜揚了揚手。

李七夜一看去，坐在那裏的竟然是陶婷，只見她一個人默默地坐在那裏，有些形單影只。

看到陶婷，李七夜不由露出了淡淡的笑容，走了進去。

“老，老師”看到李七夜走進來之後，這讓陶婷有些尷尬，因為她一開始是見到熟人就想打一聲招呼，差點忘記了李七夜的身份，畢竟現在李七夜是天神學院的老師，她是天神學院的學生。

看著陶婷站在那裏，模樣有些不知所措，李七夜淡淡一笑，說道：“坐吧。”說著也坐了下來。

陶婷坐下來之後，看著近在咫尺的李七夜，氣氛顯得有些尷尬，她都不知道該怎麼樣說好。

“老，老師，以前我不知道你，你是學院的老師，我，我，我冒犯了”最後陶婷乾笑一聲，粉臉發燒，說道。

“小事，我也只是臨時起意來天神學院的。”李七夜點了點頭，笑了笑說道。

陶婷也不由鬆了一口氣，然後叫來小二，為李七夜上了一壺好茶，她親手為李七夜泡上一杯香茗，然後默默地坐在那裏。

“有心事？”李七夜看著默默坐在那裏的陶婷，笑了笑，說道。

“沒，沒回。”有些發呆的陶婷回過神來，忙是搖了搖頭，露出笑容，只不過笑容有些勉強而己。

陶婷雖然是勉強露出笑容，但這又怎麼能逃得過李七夜的眼睛呢。

“有什麼事，可以跟我說說。”李七夜笑了笑，徐徐地說道：“有些事情，或者我能幫到你都不一定。”

換作別人，李七夜根本就懶得去多關心，但是陶婷不一樣，陶婷是出身於陶村，是陶家的後人，必要之時李七夜是願意幫她一臂之力。

“沒，沒什麼，只是一些瑣事，老師勞心了。”陶婷忙是搖頭，不敢多談。

“有人欺負你？”陶婷的小舉動，李七夜盡收入眼底，淡淡地笑著說道：“而且是男女私情之間的爭鬥。”

“老師”李七夜這話把陶婷嚇了一大跳，因為李七夜一句話就道穿了她的心事，這又怎麼不把她嚇一大跳呢。

“不用驚訝，這等事情我見多了。”李七夜淡淡地說道：“這事從來都沒有少過。”

這等小事情又焉能瞞得過李七夜的雙眼，陶婷本來就長得漂亮，性格又溫潤如玉，當然是讓許多男學生喜歡了，但是，陶婷有一個致命的弱點，那就是她出身於陶村這樣的小地方，說靠山沒有靠山，說背景沒背影，在這天神學院中又沒有人撐腰。

試想一下，這樣一個天賦又不錯，又漂亮的女孩子，除了能讓不少男學生愛慕之外，同樣也會招來一些女孩子的嫉妒。

陶婷張口欲止，但不知道該說什麼好，畢竟她與李七夜還不夠熟，更何況，她是學生，而李七夜是老師，說起來總是諸多不方便。

“若是小小的感情糾紛，且讓它過去。”李七夜淡淡地說道：“若是有人出手欺負你，你跟我說便是，什麼時候都可以，在這天院，又焉別人欺負陶家的人！”

李七夜的話頓時讓陶婷心裏面暖暖的，李七夜這話就像是大哥哥對小妹妹的呵護一樣。

她孤身一人，不遠億萬裏來天神學院求學，身邊沒有親人，身後更沒有靠山可以撐腰，對於陶婷來說，她一個人在天神學院求學也是諸多的不容易。
